# my-site
creating a new web site 

A simple task-list web app built with plain HTML, CSS and JavaScript (no install needed).

## Run it

**Option 1:** double-click `index.html` to open it in your browser.

**Option 2:** start the local server (Windows PowerShell):

```powershell
powershell -ExecutionPolicy Bypass -File serve.ps1
```

Then open http://localhost:8080/ and press Ctrl+C to stop it. Use `-Port 3000` to pick another port.
